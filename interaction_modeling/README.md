# GRIP-Based Interaction Alpha

This package builds graph-based `alpha` values for IWRE.

Pipeline:

```bash
python scripts/prepare_interaction_grip_dataset.py --logs-dir outputs/logs --out-dir outputs/interaction_grip
python -m interaction_modeling.train_future --data-root outputs/interaction_grip --output-dir outputs/interaction_grip_future
python -m interaction_modeling.distill_alpha_teacher --data-root outputs/interaction_grip --checkpoint outputs/interaction_grip_future/best.pt --out-root outputs/interaction_grip_teacher
python -m interaction_modeling.train_alpha --data-root outputs/interaction_grip_teacher --output-dir outputs/interaction_grip_alpha
```

`alpha_teacher` is generated by masking one neighbor node at a time and measuring
how much the ego future prediction loss increases. The online model distills that
teacher into one fast forward pass.

Input channels are:

```text
dx_obs, dy_obs, dvx_obs, dvy_obs, distance_obs, closing_rate, slot_index_norm, valid, is_ego
```

Node order is:

```text
ego, preceding, following, leftPreceding, leftAlongside, leftFollowing, rightPreceding, rightAlongside, rightFollowing
```
